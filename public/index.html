Port Allocation Rules / 端口分配规则

▼

English

  • New dev servers must use ports in the 4000 range
  • Each application is allocated a block of 10 ports
  • Increment by 10 for each new app (e.g., 4010, 4020, 4030...)
  • Keep all services for one app within its 10-port block
  • Main gateway/frontend uses x0, backend/API uses x1, database uses x2, etc.
  • Check the table below for available port blocks before deploying
Example: Debate App → 4010 (frontend), 4011 (API), 4012 (DB)

中文

  • 新开发服务器必须使用 4000 端口段
  • 每个应用分配 10 个端口 的区块
  • 每个新应用递增 10（如 4010、4020、4030...）
  • 一个应用的所有服务必须在其 10 端口区块内
  • 主网关/前端用 x0，后端/API 用 x1，数据库用 x2，依此类推
  • 部署前请查看下表确认可用端口区块
示例：辩论计时器 → 4010（前端）、4011（API）、4012（数据库）
